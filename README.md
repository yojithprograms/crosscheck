# CrossCheck

A mobile app that helps Fairfax County students walk, bike, or scoot to school by lower-risk routes, report near-misses, and produce a safety report for each school. Built for the 2026 Congressional App Challenge.

> Work in progress. Setup, data sources, methods and metrics, limitations, privacy, and AI use will be documented here (see `docs/DESIGN.md` §1.4).
